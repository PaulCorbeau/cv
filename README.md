# Paul Corbeau — CV

An open-source, versioned CV. One static HTML page — no build, no framework, no
dependency (Google Fonts only). Bilingual **EN / FR**, light/dark, print-to-PDF.

**Live:** https://paulcorbeau.github.io/cv/ · **Source:** you're looking at it.

Application Tech Lead · Industrial IoT & AI platform engineer — building the
software and AI that run the factory floor.

## View it

- Open `index.html` in a browser, or use the live link above.
- Toggle **EN / FR** and light/dark from the top bar.
- Export a PDF: browser **Print → Save as PDF** (the layout has print styles).

## Why a repo

Because a CV that ships as a versioned, open page is the point: it's the same way
I build everything else.
